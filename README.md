# 📚 Education Management System

A full-stack **Education Management System** developed using **ASP.NET Core MVC**, **Entity Framework Core**, and **SQL Server**. The system provides separate dashboards for **Admin**, **Teacher**, and **Student**, enabling efficient management of academic activities through a modern web application.

---

## 🚀 Features

### 👨‍💼 Admin Module

* Admin Dashboard
* Student Management (Add, Update, Delete)
* Teacher Management (Add, Update, Delete)
* Announcement Management
* Event Management
* View Student & Teacher Details

### 👨‍🏫 Teacher Module

* Teacher Dashboard
* Mark Student Attendance
* Upload Assignments
* Upload Study Materials
* Create Exams
* Enter Student Marks
* Add Student Remarks
* View Assigned Class Information

### 👨‍🎓 Student Module

* Student Dashboard
* View Attendance
* View Assignments
* Submit Assignments
* Download Study Materials
* View Exam Results
* View Announcements
* Submit Leave Requests
* Check Teacher Remarks

### 💬 Communication

* Internal Messaging System
* Inbox & Sent Messages
